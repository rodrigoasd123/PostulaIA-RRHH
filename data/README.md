# Carpeta Data - PDFs de Prueba

Esta carpeta contiene archivos PDF de prueba creados por el equipo para validar el agente de postulación sin usar datos reales de clientes o postulantes.

## Ejemplos de uso:
- Subir documentos PDF en formato digital con texto seleccionable o tablas de requisitos.
- Probar el análisis automático de perfiles, cronogramas y exclusiones.
